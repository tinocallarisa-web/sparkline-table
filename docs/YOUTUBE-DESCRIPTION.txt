The monthly review has fifty stores, twelve sales reps or two hundred products on the screen, and one question: which of them are drifting from plan, and is it a trend or one bad month? Sparkline Table by TCViz puts your hierarchy in rows with the subtotals Power BI calculates, the value of the last period, the change against the previous period or last year, and a sparkline on every row.

WHAT IT DOES
──────────────────────────────────────────
✅ Every row: rows load in segments, with no cut-off
✅ Up to 3 levels with Power BI's own subtotals, level buttons 1 · 2 · 3
✅ Value of the last period or total of the range; Δ and Δ% with a sign
✅ Five sparkline types, curve, line colour, markers and scale
✅ Bullet with qualitative bands and % of target; target line
✅ Plan, prior year and forecast as grey reference columns
✅ A plan defined only by region shows "—" below, not a meaningless variance
✅ Data bars, search box, sort by any column
✅ Click to filter (subtotals too), highlight, bookmarks, keyboard and high contrast
✅ The measure's number format, dynamic format strings included; twelve languages
✅ No network requests: everything is computed inside your report

──────────────────────────────────────────
PLAN ONLY BY REGION?
──────────────────────────────────────────
Power BI repeats the region's plan on every store. Blank it below its level:
Plan (region only) = IF ( ISINSCOPE ( Stores[Sales rep] ) || ISINSCOPE ( Stores[Store] ), BLANK (), [Sales plan] )
