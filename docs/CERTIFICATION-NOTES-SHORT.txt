WHAT TO CHECK
- Empty visual: start screen.
- Click a row: other visuals filter; click a subtotal's value: all its rows. Ctrl+click
adds; Esc clears. Bookmark, clear, apply: selection and expanded rows return.
- Right-click: context menu. Level buttons 1 2 3; Alt + click a row name: whole level.
- Keyboard: arrows move and expand/collapse, Enter selects, Esc clears.
- High contrast: status differs by shape; negative variance bar hatched.
- Format mode: click a header, a row name or a sparkline.

ROWS: matrix mapping, window of 1,000; fetchMoreData (aggregated segments) until all
rows arrive. Subtotals from the engine. Expand/collapse stored by the host
(expandCollapse). persistProperties only on an explicit click (setup guide, header
sort while editing), never in the selection callback.

PRIVACY: privileges []. No network, telemetry, browser storage or innerHTML. Row images
only from Base64 data URIs, never URLs. Start-screen links open on click via launchUrl.

Rendering events: one started/finished pair per update(), fetchMoreData included;
scroll, hover, selection and sort do not call update().
